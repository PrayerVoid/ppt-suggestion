# 内容规划-叙事（写 STORY.md 之前必读）

> 设计要求：每页只表达一个核心观点，页面标题直接给出结论或要点；目录、章节与正文层级清晰，
> 章节编号体系前后一致；正文提炼为短句和要点；内容顺序尊重原始资料逻辑；图表、文字、结论相互印证，
> 数据口径全文一致。

**去 AI 味**：本阶段产出的全部文本（标题/条目/note/insight/图表文字）必须按 `humanize.md` 的
**全量规则**逐条自查，不是只查本节提到的几条。视觉与密度规则在 `design.md` / `deck-schema.md`。

## 1. 意图（五句）

- 场合和受众：答辩 / 评审 / 汇报 / 内训 / 教学？听众是谁？
- 讲完要让人相信什么、做什么？（一句话结论）
- 页数：以内容量为准，合理拆页，不注水也不压缩到不可读。默认 8–16 页区间由内容决定。
- 必讲 / 不讲（范围边界）。
- 有无模板：有则先做模板分析（见 `source-intake.md`），全稿继承其设计语言。

## 2. 骨架

- 分章。目录声明 N 章，就必须有 N 个 `section` 扉页，编号、标题与目录逐字一致。
- 每页只表达一个核心观点；页面标题直接给出结论或要点。
- 相邻页版式不能相同；等宽卡片全稿最多 2 页，且禁止连续两页。
- 全稿至少 40% 的页用非对称或结构版式（`split` / `layers` / `rows` / `stats` / `compare` / `pipeline` / `hub` / `timeline`），不要六张一样的卡片。
- 结构页（`layers` / `pipeline` / `hub` / `timeline` / `compare` / `steps` / `rows`）至少 2 页。
- 内容顺序尊重资料逻辑；资料混乱时按领域惯例重组，但**不增删核心信息**。

## 3. 逐页字段

每页写：`title`（完整结论句）/ `type`（cover|catalog|section|content|close）/ `role`（hero|supporting）/ `layout` / `so_what`（有数据就必须有判断）。

反例：只写「2026 年增长 16.3%」——这是信息板。要写成「增长 16.3%，高基数后增速转温和，不能只看总量」。

## 4. 版式选用

| 内容 | 用 | 不要 |
|---|---|---|
| KPI / 关键数字 | `stats`（每项带 note） | 等宽卡片装数字 |
| 架构 / 分层 | `layers` + 每层 `modules` | 把模块名写成一行顿号列表 |
| 端到端链路 / 流程 | `pipeline` / `steps` | 四张一样的卡 |
| 现状 vs 目标 / 不是什么 vs 是什么 | `compare` | 左右两段文字 |
| 统一入口 / 控制平面 / 中枢 | `hub` | 一个大标题加一句话 |
| 分期落地 / 演进 | `timeline` | 编号清单 |
| 并列论点 / 机制 | `points` | 六张等宽卡片 |
| 对比 / 主次 | `split`（宽窄 60:40） | 左右对半 |
| 数据对比 | `table`（表头突出、行高适中、避免厚重底纹） | 逐条罗列 |
| 目录 | `catalog` | `columns` 冒充目录 |
| 章节切换 | `section` | 普通正文页写「第三章」 |
| 本页结论 | `insight`（全稿 3–6 条，别每页都放） | 每页一条「所以呢」 |
| 趋势 / 构成 | 数据图表（折线/柱状/饼图），优先原生可编辑图表 | 截图、图片 |

## 5. 内容要具体（配合 humanize.md 使用）

- 每个 `items` 条目都要有 `body`，是**能读出信息的句子**（≥10 字），不是「高效」「智能」这类标签。
- 用户只给了模块名 / 关键词时，自己补出机制、代价、边界：这层做什么、不做什么、失效会怎样。补不出来就说明该页不该单独成页，合并它。
- 有数字必须给 `note` 说明来源或含义，别只放一个孤零零的数字。
- 一页只写一个判断，但给出 3 个以上支撑事实（或合并页）。

## 6. STORY.md 最小结构

```markdown
# 意图
- 场合/受众：...
- 一句话结论：...
- 页数：...
- 必讲/不讲：...
- 模板：有/无（有则附模板摘要）

# 骨架
- 目录 01 xxx → section 页
- 目录 02 xxx → section 页
...

# 逐页
1. [cover] 标题 — 副标题
2. [catalog] 目录
3. [section] 01 章名
4. [content] 结论句 — layout=layers — so_what=...
```
