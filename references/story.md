# 内容规划-叙事（写 STORY.md 之前必读）

> 设计要求：每页只表达一个核心观点，页面标题直接给出结论或要点；目录、章节与正文层级清晰，
> 章节编号体系前后一致；正文提炼为短句和要点；内容顺序尊重原始资料逻辑；图表、文字、结论相互印证，
> 数据口径全文一致。

**去 AI 味**：本阶段产出的全部文本（标题/条目/note/insight/图表文字）必须按 `humanize.md` 的
**全量规则**逐条自查，不是只查本节提到的几条。视觉与密度规则在 [design.md](design.md)，字段与机械检查在 [deck-schema.md](deck-schema.md)。

## 1. 意图（五句）

场合、受众、页数和模板风格模式等已在阶段二问完，这里整理成五句，不重复提问：

- 场合和受众：答辩 / 评审 / 汇报 / 内训 / 教学？听众是谁？
- 讲完要让人相信什么、做什么？（一句话结论）
- 页数：以内容量为准，合理拆页，不注水也不压缩到不可读。默认 8–16 页区间由内容决定。
- 必讲 / 不讲（范围边界）。
- 模板风格模式：完全遵循/半自主时先做模板分析（见 `source-intake.md`）；两个完全自主模式按用户指定或白底极简规则设计。

## 2. 骨架

- 分章。目录声明 N 章，就必须有 N 个 `section` 扉页，编号、标题与目录逐字一致。
- 每页只表达一个核心观点；页面标题直接给出结论或要点。
- 内容顺序尊重资料逻辑；资料混乱时按领域惯例重组，但**不增删核心信息**。
- 按 [design.md 的页面节奏](design.md#5-页面节奏) 安排密度与全稿版式变化，再按 [layout-types.md](layout-types.md) 选择表达关系。采样候选只作起点，不代替按内容选型。
页面和逐页讲稿直接对观众陈述事实与判断，不出现「参考资料」「资料显示」「来源于资料」「材料第几部分」等制作溯源。输入文件与段落映射只写内部证据；论文、著作等真实外部引用保留对应出处。每页默认显式编写自然可口述的 `notes`，不能把制作过程写成讲稿。

## 3. 逐页字段

每页写：`title`（完整结论句）/ `type`（cover|catalog|section|content|close）/ `role`（hero|supporting）/ `layout` / `so_what`（有数据就必须有判断）。

反例：只写「2026 年增长 16.3%」——这是信息板。要写成「增长 16.3%，高基数后增速转温和，不能只看总量」。

## 4. 从判断选择信息结构

按 [layout-types.md](layout-types.md) 选择版式与图文构图，不按页面外观推断信息关系。每页先说明它要证明什么，再安排依据、解释和边界：对照必须有可比较对象，中心关系必须有真实组成或依赖，时间轴必须有时间顺序。数字、引文与图片不足以独立成页时，配真实上下文或合并，不为版式制造内容。

## 5. 内容要具体（配合 humanize.md 使用）

- 每个 `items` 条目都要有 `body`，是**能读出信息的句子**（≥10 字），不是「高效」「智能」这类标签。
- 用户只给模块名 / 关键词时，从资料补全机制、代价与边界：这层做什么、不做什么、失效会怎样。资料不支持就列缺口或合并，不能自行推断为事实。
- 有数字必须给 `note` 说明来源或含义，别只放一个孤零零的数字。
- 一页只写一个判断，但给出 3 个以上支撑事实（或合并页）。

高密度资料的视觉分组按 [design.md](design.md#6-对齐留白与高密度组织)；本阶段明确论点与论据、阶段与标签、图片与事实的对应关系，不为统一容器而省略关键信息。

## 6. STORY.md 最小结构

```markdown
# 意图
- 场合/受众：...
- 一句话结论：...
- 页数：...
- 必讲/不讲：...
- 模板：有（完全遵循）/ 无（有则附模板摘要）
- 复用资料图片：是/否
- 拓展：动效 / 几何装饰 / 特殊排版 / 无

# 骨架
- 目录 01 xxx → section 页
- 目录 02 xxx → section 页
...

# 逐页
1. [cover] 标题 — 副标题
2. [catalog] 目录
3. [section] 01 章名
4. [content] 结论句 — layout=layers — so_what=...
```
