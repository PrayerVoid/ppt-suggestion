# 模板继承（有模板时必读）

> 设计要求：严格遵循模板——分析页面比例/母版版式/页眉页脚页码/主辅色/分隔线色块装饰/图片放置逻辑/
> 各类型页版式规律，优先复用模板已有版式，不因内容不同重新设计整套视觉系统；引用资料中的现成图片
> 保持清晰完整；页眉页脚页码沿用模板设置，不随意删除或移位；页面管理优先依托母版和版式。

## 1. 流程

1. 阶段一跑 `analyze_template.py <模板.pptx> -o 模板摘要.md`，人工核对摘要完整（页面比例、母版版式、
   页眉页脚页码、主辅色、装饰元素、图片放置逻辑、各类型页版式规律）。
2. 阶段二按摘要设计 deck.json：目录/章节/正文与模板的版式类型一一对应。
3. 阶段三渲染时加 `--template`，渲染器按版式匹配规则填充原生占位符，继承模板设计语言。

## 2. 版式匹配规则（渲染器行为）

| deck slide 类型 | 优先匹配的模板版式 |
|---|---|
| `cover` | 标题版式（名称含 封面/标题/title） |
| `section` | 章节版式（名称含 章节/过渡/节/section/header） |
| `catalog` / `content` | 内容版式（名称含 内容/正文/标题和内容/content/two content） |
| `close` | 结束版式（名称含 结束/结尾/end/thanks/谢谢） |

- 无匹配时回退「标题+内容」或空白版式，并把回退情况记入交付说明。
- 标题填入版式的标题占位符（继承母版字号/字体/位置）；正文结构块在内容区绘制。
- 结构块只用**模板主题色**（accent1–6 等），不引入模板之外的新颜色；不加阴影/发光/渐变。
- 模板原有页面会被清空重建（deck.json 定义全稿），但**母版、版式、主题、页眉页脚页码保留**。

## 3. 主题色使用边界

- 文字：用模板 `tx1/dk1`（正文深色）与 `dk2`（次要）色值。
- 强调：用 `accent1`（首选），必要时 `accent2`；同一页不超过两种强调色。
- 面板/背景：用 `lt2/pale` 类浅色；不新增自造颜色。
- 若模板主题色读取失败，渲染器回退到默认白底低饱和色并提示。

## 4. 占位符填充规则

- 标题占位符：填 deck 的结论句 title。
- 副标题/正文占位符：按 deck 内容填充；占位符的文字样式继承母版（不手动改字号颜色）。
- 不要删除模板版式里的页眉、页脚、页码、logo 等母版元素。
- 内容放不下的占位：交给渲染器的排布，超出部分由 `validate_pptx.py` 报溢出后按 `validation.md` 修复。

## 5. 能力边界与已知限制（如实使用）

- 渲染器做的是**内容填充 + 最小原生形状**：复杂模板动画、SmartArt 重排、母版级新增版式不在支持范围。
- 如果模板的特殊页型（如特定图文版式）需要保留，先在 deck.json 里用对应 block 表达，渲染器按内容区放置。
- 渲染结果仍要过 `validate_pptx.py` 与 `validation.md` 的人工清单（对齐、间距、页眉页脚完整性）。
- 交付时说明模板继承情况（哪些版式被复用、有无回退），让用户知道可在 PowerPoint 里继续微调。
