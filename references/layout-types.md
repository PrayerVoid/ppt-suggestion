# 排版类型与构图选型

本文件负责按信息关系选择版式和图片构图；字段、容量见 [deck-schema.md](deck-schema.md)，视觉与密度见 [design.md](design.md)。页面 `type`、内容 `kind` 与上下/左右等构图方式是不同层次：同一种构图可以承载流程、图片或论证，不为每种外观创建 kind。

## 核心版式

核心共 26 个 kind，无需启用特殊排版。

| 信息关系 / 用途 | 核心 kind 或页面 type | 选择边界 |
|---|---|---|
| 封面、目录、章节与结束 | `cover` / `catalog` / `section` / `close`；目录 `agenda` | 页面 type 不等于内容 kind；默认封面白底，有模板按其已有图片背景继承 |
| 开篇主张、结论、短标签 | `lead` / `insight` / `chips` | 辅助 block，不能单独充当正文页主体 |
| 并列论点 / 补充说明 | `points` / `callouts` / `columns` | 列数取决于真实分组，正文句子完整，避免机械三列 |
| 主次论证 / 主文注释 | `split` / `asym` / `marginalia` | 主次论证优先 `split`；`asym` 为约 7:3 的主次区域；`marginalia` 的边注回指定义、边界与证据 |
| 对照 / 表格 / 四类分类 | `compare` / `table` / `quadrant` | `quadrant` 是四组分类，不生成二维轴、阈值或数据点；真正矩阵按资料定义维度，用 `table` 或合适图表 |
| 分层、泳道、流程 | `layers` / `rows` / `steps` / `pipeline` | 节点关系真实，流程顺序有依据，不用卡片冒充关系 |
| 时间演进 / 中心关系 | `timeline` / `hub` | `hub` 为日常中心关系；不能为图片凑出依赖 |
| 核心数字 / 多指标 / 数据关系 | `bignum` / `stats` / `chart` | 一个重点用 `bignum`，多个指标用 `stats`，趋势/构成等用 `chart`；数字、口径与来源真实，创建图表或 KPI 时加载 dataviz skill |
| 引用 / 原图 / 公式 | `quote` / `figure` / `formula` | 引文可追溯；图片获准复用且等比；公式原生可编辑，不能伪造引用或缺图 |
| 规整分组 / 卡片组 | `cards` | 仅为分组服务，条目整行排布；遵守 design 的卡片限制，不能借 `quadrant` 规避 |

`quote` 引文短时可配真实上下文与解释（如 `callouts`、`points` 或 `rows`）；`bignum` 用 body/items 交代来源、比较口径与含义。内容不足就合并页面，不能虚构引文、数字或说明凑字数。来源无法落在 block 专有字段时，写页面或根对象 `source`。

## 页面构图

| 构图 | 信息关系与实现 | 边界 |
|---|---|---|
| 全屏主题 | 模板 `cover` 继承已有背景照片；正文原图用 `figure` | 默认封面白底，不因构图选择引入深色背景 |
| 上下布局 | 概述与证据、图片与说明依阅读顺序组合，如 `lead` + `figure` / `steps` | 按实际高度留空间，不创建额外 kind |
| 左右布局 | 图文 `figure.side`，主次 `split` / `asym`，对照 `compare` | 左右摆放本身不构成对比关系 |
| 纵列布局 | 文字模块 `columns`；目录 `catalog` + `agenda` | `columns` 不支持图片字段；多图使用模板图片位或拆页 |
| 矩阵布局 | 交叉维度 `table`，规整分组 `cards`，四类判断 `quadrant` | 矩阵外观不证明存在二维数值关系 |
| 上下分区与信息带 | `lead` + `timeline` / `points`，或继承模板已有横带 | 保留主次与留白，不额外加装饰色带 |
| 中心环绕 | 日常优先 `hub`；短节点环绕可选扩展 `radial`，嵌套关系才用 `concentric` | 中心、组成或依赖关系必须真实 |
| 卡片分组 | 可独立阅读的信息组用 `cards` 或 `columns` | 流程和演进改用关系 block，不把全稿卡片化 |

## 图片构图

先确认图片来源及复用许可，再确定图片数量、主次和图文区域。可用等尺寸占位框规划对齐与间距，随后换成真实图片；占位灰框不能作为缺图替代品交付。数据、标注、单位、图例与关键对象必须完整可读。

- **单图与文字**：用 `figure` 的左右图文或上下组合，等比完整放入。`height` 只限定图片区域，整体占用高度仍包含侧栏与图注，见 schema。
- **一主多辅**：主图用 `figure`，辅图放后续页或模板已有多图位；不以透视缩小重要证据，不新增立体底座。
- **等权多图与平面网格**：用模板已有图片位，统一间距、图注和顺序；无合适模板时分组拆页。`columns` 不能承载图片，`figure` 不自动生成多图网格。
- **连续图片与时间顺序**：保持图注与顺序；有时间关系用 `timeline`，有真实中心关系用 `hub`。无中心关系不强加环绕、连线或依赖。
- **形状裁剪与方向构图**：证据图保持完整；非证据照片仅在模板已有适用裁剪位时考虑继承。特殊排版的 `diagonal` 只是浅色方向提示，不切割图片。
- **能力边界**：核心及特殊排版不自动实现图片布尔蒙版、背景填充、弧形胶片、三维展台、透视地毯或斜铺旋转。用平面分区、主辅图、统一网格或拆页表达信息；特殊排版也不自动启用 Morph。

## 特殊排版

只有用户明确启用特殊排版时才接入以下四个 kind；接入步骤、字段与示例见 [special-layout/EXT.md](../extensions/special-layout/EXT.md)。

| kind | 构图与使用边界 |
|---|---|
| `diagonal` | 低密度方向主张的浅色斜切；不裁剪、斜铺或透视图片 |
| `radial` | 短节点沿椭圆分布的中心关系；日常中心关系优先 `hub` |
| `ring` | 固定圆环衬托单个真实指标；不编码比例，不是环形数据图或胶片 |
| `concentric` | 确有嵌套关系的 2–3 层同心圆；圆面积不编码数值 |

模板模式按已有模板位和 map 填充；选择某个 kind 不会让 `template_fill.py` 自动获得自由坐标布局能力。所有版式仍须满足视觉、容量、事实与最终校验要求。
