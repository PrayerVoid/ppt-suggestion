# 视觉、密度与页面节奏

本文件负责视觉规范、信息密度、页面节奏与采样职责。信息和叙事见 [story.md](story.md)，语言改写见 [humanize.md](humanize.md)，版式与图片构图选型见 [layout-types.md](layout-types.md)，字段与机械门槛见 [deck-schema.md](deck-schema.md)。

## 1. 视觉基线与适用模式

完全自主默认专业、克制、白底极简；用户指定其它风格时记录其颜色、字体、密度与参考风格约束。完全遵循保留模板原版式数量和几何；半自主保留模板比例、背景、母版装饰、字体配色、页眉页脚，清除中央内容及原版式后自主排版，见模板继承文档。

- 默认以白底为主，单套低饱和强调色；同级字段同处理，正文尽量黑色，以字号与字重建立层级。
- 不用阴影、3D、发光、渐变、复杂背景纹理，不为填空添加无意义图形或英文点缀。自主设计禁止暗色背景；模板已有背景按继承规范。
- 不采用宣传路演风、彩色边框和机械的“彩色小页标题 + 大黑主标题”；不让装饰压过内容。
- 几何装饰按扩展启用；底纹必须单独明确允许，且通过内容保护与对比度检查。默认不加角饰或底纹。
- 配色、字号、间距集中在渲染器副本常量中，deck 不携带 color/fontSize/hex。模板 map 的主题色和尺寸是模板编辑参数，按 template-inherit 使用。

## 2. 采样职责

`sample_style.py` 只为两个完全自主模式提供 palette、基础常量和逐页 block 候选；完全遵循和半自主不采样。最终取舍按资料和用户约束，不能让随机性改变事实、数字、公式、图表数据或素材许可。

| 层次 | 采样器行为 | 执行者职责 |
|---|---|---|
| 颜色过滤 | 检查预设文字/背景对比度组合；正文目标 ≥4.5:1，FAINT 元数据使用独立阈值 | 最终语义文字小字 ≥4.5:1、大字 ≥3:1；低对比仅用于次要脚注/页码，不能承担论据 |
| 概率偏好 | 全色相环采样，场景色相轻微加权 1.35 倍；高饱和、近纯色与过亮强调色降权，非对称/结构加权、卡片降权 | 低饱和不等于固定偏绿；单次少量候选可能撞色，按内容取舍 |
| 候选序列 | 避免相邻正文候选主版式重复、连续 cards/columns；限制 cards 候选页数 | 最终 deck 的 cards/columns 合计上限与机械检查仍须通过 |
| 软目标 | 尝试满足 40% 非对称/结构、2 页结构、5 种版式和 insight 数量；未满足项写入 `unmet_soft_targets` | 采样不证明最终 deck 合格，按下文规范和 schema 复核 |
| 资料触发 | 不随机推荐 `bignum`、`quote`、`chart`、`formula`；`figure` 需 `--figure`，主次候选优先 `split` | 必须由真实数字、引文、数据、公式或获准原图触发；`stats` 候选同样不能成为补数理由 |

用户指定颜色可用 `--force-color`；它会放行强调色/白底的一项过滤并给出低对比告警，不能据此把低对比色用于小字。保存 seed、候选 ID、场景、页型、强制颜色、完整 palette/base 和用户覆盖项到 `style.json`，精确复用以保存的参数值为准。候选 ID 从 0 开始，输出常量时保持全部采样参数一致。需要比较外观可运行 `style_showcase.py`。

## 3. 字体

- 全文统一一种中文字体（如微软雅黑、楷体），标题、正文、表格、图注、页脚、流程图与图表标签不混用。
- 英文与数字原则上同字体；中文字体不适合英文时（如楷体）用 Times New Roman。
- 数学公式、化学式、代码按学科规范。

## 4. 内容密度

密度依靠事实、机制、边界与依据。写不出时合并页面或回到资料缺口门，不用空话凑字，不缩小字号硬塞。

| 页面 | 内容要求 |
|---|---|
| 封面 | 主标、副标和 3–5 个短标签（用 `·` 分隔） |
| 目录 | 3–8 条，每条有编号、章名和一句摘要 note |
| 章节扉页 | 大号编号、章名和一句副标 |
| 结构页 | 关系 block 占主体；每个节点说明其职责、输入输出或边界，字段按 schema |
| 数字页 | 多指标用 3–4 个 stats（value/label/note）；单个数字重点用 bignum 并交代口径与依据，最多 2 页 |
| 引用页 | 原文与可追溯来源，短引文配真实上下文，内容不足合并 |
| 卡片页 | 每项一句有信息的判断，遵守下文页数限制 |

无模板正文总字数至少 110 字，存在的 items[].body 至少 10 字；机械计数口径见 schema。字段不使用 body 的节点也要提供能读出信息的说明，不能以标签替代依据。公式和图片页同样需要足够上下文，不能伪造说明。

完全遵循和半自主按模板容量安排内容；`--template-mode` 跳过字数与版式多样性机械门槛，但不豁免事实、容量、标题、字段、图表和公式检查。快速模式不另行放宽脚本门槛。

## 5. 页面节奏

以下为规划规范；模板模式以继承版式与容量为准，并避免机械重复母页：

- 相邻正文页不使用相同版式；`cards`/`columns` 合计全稿最多 2 页，且不连续。`quadrant` 只表达四类判断，普通四卡分组不能改名规避。
- 正文页至少 40% 使用非对称或结构表达：`split`、`asym`、`marginalia`、`bignum`、`layers`、`rows`、`stats`、`compare`、`pipeline`、`hub`、`timeline`。
- 至少 2 页结构页：`layers`、`steps`、`rows`、`pipeline`、`hub`、`timeline`、`compare`。
- 全稿正文至少 5 种版式，辅助 `lead`、`insight`、`chips` 不计。`insight` 全稿 3–6 条，不机械每页一条。
- 单栏、双栏、图文、表格、时间轴、流程、架构、图表、关键数字按信息关系选择，具体见 layout-types。

上述 40%、2 页结构、bignum 页数与 insight 数量需人工复核；deck_check 只阻断完全没有结构表达等已实现条件，详见 schema。不能把脚本未报错解释为这些规范已满足。

## 6. 对齐、留白与高密度组织

- 同页按统一基准线对齐，边距一致；相关元素组内间距小于组间间距，图注和来源靠近对应图。
- 行距按内容角色安排：多行标题约 1.2–1.3×，密集正文约 1.4–1.5×，普通正文约 1.5–1.6×，稀疏页可用 1.6–2.0×。段间间距大于行内间距，列表项间距小于段间距；最终以容量和真实渲染为准。
- 视觉重量由面积、明度、密度共同决定。内容页避免无理由全部挤在一侧，另一侧基本空白；可按内容调整或居中，不为填空增加装饰。
- 容器表达真实分组、层级或边界，同层同处理。文字量不同可按信息量分配宽高；较大区域可居中平衡，但不能暗示不存在的数值比例或改变阅读顺序。
- 主次先于外观：主题名称承担主标题，宣传语降为副标题；按语义断句，避免等宽机械换行与孤立单字。
- 论点和论据分层：从资料提炼有依据的小标题，论据保留其下；阶段的平台/渠道标签与对应阶段关联，不强制改成图标。语言改写只按 humanize 自查。
- 四组内容可对称排布并统一标题与正文轴线。中部没有信息用途时保持留白，不加入产品图或环绕线填空。
- 数字、小数、千分位、百分号与引号按内容语言统一。容量不足按 validation 拆页，不增加句式脚本门禁。

## 7. 图表、公式与图片的视觉要求

图表类型匹配真实数据关系，轴名称、单位、图例与必要来源齐全，标签不过密；配色继承模板实际可见主辅色或渲染器色板，不另起颜色。图表外不嵌套冗余圆角卡片。原生/回退实现与各模式边界见 [charts/EXT.md](../extensions/charts/EXT.md)，字段见 schema。

公式以原生可编辑对象呈现，不用截图或纯文本拼公式。复用图片须获准、清晰、完整、等比且无残留水印；不重绘可直接引用的证据图。图片构图与能力边界见 layout-types；机械阈值和最终可读性检查见 validation。


## 模板重构契约

模板密度以真实信息覆盖为目标：每页补足材料中的论据、条件、机制、边界和来源，不能只替换几个短标签。优先容量合适的正文页；必要时拆页、增页。半自主自主布局不继承中央卡片，完整遵循不混入自主几何调整。
