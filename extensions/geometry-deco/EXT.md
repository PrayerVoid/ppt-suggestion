# 拓展：几何装饰

## 何时启用

仅当用户在"询问用户"阶段明确选了"几何装饰"（或说"炫酷""要设计感"）时才读本文件。
默认外观是白底极简、没有任何角落装饰，不启用就不要加。

## 做什么

对已渲染好的成品 pptx 后处理，给整份 deck 加**风格一致**的几何装饰（圆、描边圆、小色块、细线）：

- 一份 deck 只用一种图案族（`circles` 圆组、`blocks` 方块、`lines` 细线加色块），由 `--seed` 决定；不传 `--seed` 用 `circles`。
- 角色固定，不做逐页随机：

| 页面类型 | 装饰 |
| --- | --- |
| cover / close | 大构图，贴右侧上角 |
| section | 同一构图上下翻转，贴右侧下角 |
| catalog / content | 完全相同的小角标（同形状、位置、大小、颜色），贴右下角 |

- 自动避让：先读每页所有非装饰形状（含组合内子形状）的位置，整套选一个对同类所有页都不冲突的角落和缩放（装饰与文字框至少留 0.12 英寸）。没有这样的方案时，冲突的页省略装饰，并在输出里打印页号。避让按文本框外框计算，标题框很宽时大构图会缩小。
- 装饰放在每页最底层，形状统一命名 `DECO_<序号>`；`validate_pptx.py` 会忽略这个前缀。重复运行会先删掉已有的 `DECO_` 形状。

## 用法

```
python extensions/geometry-deco/add_deco.py 成品.pptx --deck deck.json --out 成品_装饰.pptx [--seed N] [--accent HEX]
```

| 参数 | 含义 |
| --- | --- |
| `--deck` | 必填，用来读每页 `type`；页数必须与 pptx 一致 |
| `--out` | 输出路径，不覆盖输入 |
| `--seed` | 可选，选择图案族；换种子换图案族 |
| `--accent` | 可选，装饰主色，默认 `4F6082`。应与渲染器副本里的 `ACCENT` 一致；浅色块自动取该色与白色 12% 混合 |

## 注意

- 装饰色必须与正文强调色一致，不要另起颜色。
- 运行顺序：渲染 → `formula.py` → 本脚本 → 动效（如启用）→ 结果校验。每次重新渲染后都要重跑。
