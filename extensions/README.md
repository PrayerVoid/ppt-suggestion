拓展索引。用户没有明确启用拓展时，不需要阅读本目录。

| 拓展 | 目录 | 做什么 | 启用条件 |
|---|---|---|---|
| 动效 | `animation/` | 页间转场 + 内容页逐块淡入，对成品 pptx 后处理 | 用户在询问阶段选了"动效" |
| 几何装饰 | `geometry-deco/` | 对成品 pptx 按页类型加几何装饰形状 | 用户选了"几何装饰" |
| 特殊排版 | `special-layout/` | 追加 `bignum`、`asym` 两个 block，粘进渲染器副本 | 用户选了"特殊排版" |

约定：
- 每个子目录的 `EXT.md` 是该拓展的完整说明，只读用户选中的那几个。
- 后处理类拓展（动效、几何装饰）在排版渲染和 `formula.py` 之后、结果校验之前运行，顺序为几何装饰 → 动效，输出新文件，不覆盖原 pptx。
- 装饰形状命名以 `DECO_` 开头，公式形状以 `FORMULA_` 开头，其他拓展靠前缀识别它们。
- 脚本用项目 `.venv` 的 python 运行。
